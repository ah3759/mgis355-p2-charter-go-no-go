# Data specification

This project models a Carolinas charter captain deciding the evening before whether to run a booked trip or offer a reschedule. Each row is one synthetic inshore (4 hours) or offshore (8 hours) trip. The data is generated by `generate_data.py` with seed 355; it demonstrates that the pipeline works, not that real fish behave this way.

## Dataset

- Rows: 1896; columns: 18; seasons 1-3 represent 2022-2024.
- Overall productive base rate: 0.629.
- Inshore base rate: 0.640; offshore: 0.599.
- Season base rates: {"1": 0.54337899543379, "2": 0.6774716369529984, "3": 0.6720257234726688}.

## Story and planted effects

The generator plants water-temperature sweet spots near 70F inshore and 74F offshore, higher wind lowering inshore catch, moving tide outperforming slack tide inshore, and wave height above about 3 ft lowering offshore catch. It also plants a hot streak represented by `trailing_3day_catch_rate`, small species effects, and a small positive days-since-front effect. Planted null effects are party size, moon phase, forecast air temperature, and inshore wave height.

`bites_logged_during_trip` is leaky because it is recorded after the trip. It raised test AUC from 0.729 to 0.983, so it is excluded. The trailing rate uses earlier days only and is known the evening before; removing it changed AUC from 0.729 to 0.668, which is evidence of predictive signal, not leakage by itself.
